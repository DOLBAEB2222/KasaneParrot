# KasaneParrot 🦜✉

**Почтовая служба Kasane-попугаев** — плагин для **Paper 1.21.8**:
приручите попугая, наденьте мешочек и отправляйте предметы другим игрокам
с настоящим полётом, живым GUI и умной посадкой.

## Как это работает (геймплей)

1. **Приручение** — ванильное: покормите дикого попугая семечками
   (пшеница/тыква/дыня/свёкла).
2. **Мешочек** — скрафтите ванильный **Bundle** (мешочек).
   **Shift+ПКМ** мешочком по *своему* приручённому попугаю — мешочек
   надевается **навсегда**, «моделька» попугая меняется
   (смена варианта + ресурспак [Pesky Parrots](#ресурспак)).
3. **Отправка** — **ПКМ по попугаю с предметом в руке** или **Shift+ПКМ** —
   открывается ванильное GUI (Paper Menu Type API):
   - список **онлайн-игроков** (головы, пагинация, живое обновление
     при входе/выходе — окно не переоткрывается);
   - выбор адреса: **к игроку** или **к его точке спавна**
     (пункт появляется только если точка есть);
   - подтверждение с превью посылки и временем в пути.
4. **Полёт** — попугай взлетает на **100 блоков** и исчезает.
   Время доставки = расстояние между игроками, от **30 секунд до 5 минут**.
5. **Посадка** — попугай появляется в **50 блоках над целью** и плавно
   снижается. Умный анализ активности: стоит / идёт / бежит / элитры —
   с учётом этого выбирается место и стратегия посадки.
6. **Выдача** — предмет остаётся на земле в **невидимой рамке**.
   **ЛКМ по рамке — предмет выпадает, рамка исчезает** (правый клик
   заблокирован: посылку можно только «сбить»).
7. **Возврат** — попугай улетает вверх, возвращается к хозяину и садится
   **на плечо**. Теперь это обычный попугай с кастомной текстурой.

## Сборка

```bash
./gradlew build          # → build/libs/KasaneParrot-1.0.0-SNAPSHOT.jar
```

Требуется JDK 21+. CI (GitHub Actions) собирает jar на каждый пуш —
артефакт `KasaneParrot-jar` во вкладке Actions.

## Установка

1. Положите jar в `plugins/`.
2. Положите `messages_ru.yml`/`config.yml` создадутся автоматически.
3. (Опционально) разместите `Pesky Parrots.zip` на хостинге и укажите
   `resource-pack.url` + `sha1` в конфиге (режим `PROMPT`/`FORCE`).

## Структура проекта

```
src/main/java/dev/dolbaeb/kasaneparrot/
├── KasaneParrotPlugin     — сборка модулей, жизненный цикл
├── module/                — система модулей (enable/disable/reload)
├── config/                — типизированный конфиг (KasaneConfig)
├── text/                  — MiniMessage-сообщения (messages_ru.yml)
├── key/                   — NamespacedKey/PDC-хелперы
├── parrot/                — реестр курьеров, состояния, смена «модели»
├── flight/                — анализ активности цели, поиск посадки, Безье-пути
├── delivery/              — машина состояний доставки, расчёт времени
├── gui/                   — ванильные меню (MenuType API), кэш голов
├── frame/                 — невидимые рамки доставки
├── shoulder/              — посадка на плечо
├── listener/              — события (клики, join/quit, защита)
├── event/                 — кастомные события (расширяемость)
├── command/               — /kasane
└── util/                  — easing, векторы, время
```

Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) (архитектура),
[docs/RESEARCH.md](docs/RESEARCH.md) (исследование API и референсы).

## Команды и права

| Команда | Право | Описание |
|---|---|---|
| `/kasane help` | `kasaneparrot.command` (все) | справка |
| `/kasane reload` | `kasaneparrot.admin` | перезагрузить конфиг |
| `/kasane status` | `kasaneparrot.admin` | статистика доставок |
| `/kasane pack` | `kasaneparrot.admin` | инфо о ресурспаке |

## Ресурспак

`Pesky Parrots.zip` (в корне репозитория) — OptiFine-пак: перетекстурирует
все 5 вариантов попугаев (~47 скинов на вариант, CEM-модель, emissive).
Смена «модельки» в плагине реализуется сменой варианта попугая
(`parrot.model.courier-variant` / `after-delivery-variant` в конфиге),
который пак отрисовывает по-своему. Для раздачи игрокам обновите
`pack.mcmeta` (`pack_format` 9 → актуальный для 1.21.8) и укажите URL в
конфиге. Подробности — в [docs/RESEARCH.md](docs/RESEARCH.md).
